# konnyaku

リアルタイム音声翻訳字幕オーバーレイ (デフォルト 日本語→英語、言語選択可)。ハンズオン発表でプロジェクター / Google Meet の画面共有に翻訳字幕を映すための macOS メニューバーアプリ。

Named after ほんやくコンニャク (honyaku-konnyaku, the translation gadget from Doraemon) — honyaku (translation) → konnyaku.

## 特徴

- **完全オンデバイス**: 音声認識 (SpeechAnalyzer) も翻訳 (Translation framework) も Apple 純正のオンデバイス処理。音声が外部サーバーに出ない
- **2 段字幕**: 話した言語の書き起こしを即時表示し、翻訳も話し中からリアルタイムに追従表示する (設定で「文の確定を待ってから翻訳」に切り替え可)
- **言語選択**: 入力言語 (音声認識) と出力言語 (翻訳先) を設定画面から選択。対応言語は OS から動的に列挙
- **画面全体オーバーレイ**: クリック透過・最前面・全 Space 追従。プロジェクターへのミラー出力にも Meet の画面全体共有にもそのまま映る。ドラッグで位置調整可、文字サイズ 3 段階。複数モニター接続時は設定画面から表示先モニターを選択可
- **共有ビュー (ウィンドウ共有対応)**: 選んだアプリのウィンドウをキャプチャして字幕を合成した専用ウィンドウを表示。Meet の「ウィンドウ共有」で画面全体を映さずに字幕付きで共有できる (サムネイル付き一覧から選択。初回のみ画面収録の許可が必要)
- **依存ゼロ**: Swift + Apple フレームワークのみ。UI は日本語 / 英語対応

## 動作要件

- macOS 26.0+ (Apple Silicon)
- マイクへのアクセス許可
- 画面収録の許可 (共有ビューを使う場合のみ)
- 日本語の音声認識モデルと日本語→英語の翻訳言語モデル (初回にダウンロード)

## インストール

```bash
brew install --cask kanka-jp/tap/konnyaku
```

ad-hoc 署名のため、初回起動時は Gatekeeper にブロックされる。システム設定 → プライバシーとセキュリティ → 「このまま開く」で許可するか、quarantine 属性を外す:

```bash
xattr -dr com.apple.quarantine /Applications/Konnyaku.app
```

zip を直接使う場合は [Releases](https://github.com/kanka-jp/konnyaku/releases) からダウンロードする (同じ Gatekeeper 許可が必要)。

## ビルドと起動

```bash
make run
```

`make app` で `dist/Konnyaku.app` が組み立てられ (ad-hoc 署名)、`make run` はそれを起動する。

## 使い方

1. メニューバーの 💬 アイコン → 「字幕を開始」
2. 初回はマイク許可のプロンプトに応答する。翻訳言語モデルが未インストールの場合は「翻訳モデルのセットアップ…」からダウンロードする
3. 喋ると画面下部に書き起こし (上段) と翻訳 (下段) の字幕が出る
4. 言語・翻訳・文字サイズなどはメニューの「設定…」で開く設定画面から変更できる (入力と出力が同じ言語なら書き起こしのみ表示)
5. 位置を変えたいときは「オーバーレイを移動 (ドラッグ)」を ON にしてドラッグ → OFF で固定 (位置は記憶される)
6. 複数モニターを使っている場合、設定画面の「表示モニター」から字幕を出すモニターを選べる (選択したモニターの初期位置に移動する。「自動」はこれまでどおりドラッグした位置を復元する)
7. Google Meet で共有する場合は次のどちらかを選ぶ (通常のウィンドウ共有にはオーバーレイが映らない):
   - **画面全体の共有**: オーバーレイがそのまま映る (従来どおり)
   - **ウィンドウ共有 + 共有ビュー**: メニューの「共有ビューを開く…」でサムネイル付きの一覧から映したいウィンドウを選んで「このウィンドウの共有を開始」を押すと、キャプチャ映像に字幕を合成した「Konnyaku 共有ビュー」ウィンドウが開く。Meet ではこのウィンドウを共有する。共有元のアプリはそのまま操作してよい (共有ビューが背面でもキャプチャは継続する)。共有元ウィンドウの最小化だけは映像が止まるため避ける。初回は画面収録の許可 (システム設定 → プライバシーとセキュリティ → 画面とシステムオーディオの収録) とアプリ再起動が必要
   - 字幕を映像に重ねたくない場合は、設定の「共有ビューの字幕配置」を「映像の外の黒帯に表示」にすると、字幕専用の帯が付き映像と重ならない。字幕 (帯) の上下は「共有ビューの字幕の表示位置」で選べる

## 設定ファイル

設定は `~/.config/konnyaku/` 配下のプレーンテキストで管理される (`XDG_CONFIG_HOME` 尊重):

- `config` — 入力/出力言語・文字サイズ・低遅延翻訳・リアルタイム翻訳・AI 補正・表示モニター (`key = value` 形式、行頭 `#` でコメント。インラインコメント非対応)。設定画面からの変更もここへ書き戻され、手編集は次回起動時に反映される
- `vocabulary.txt` — カスタム語彙 (1 行 1 語)。音声認識で誤認識されやすい専門用語・固有名詞を書くと認識がバイアスされる

オーバーレイのドラッグ位置・サイズはディスプレイ構成依存の状態のため設定ファイルには含まれない (代わりに UserDefaults で管理)。表示先モニターの選択自体は他の設定と同様に `config` へ永続化され、モニターの抜き差し・再起動をまたいでも同じモニターが復元される (該当モニターが見つからない場合はメインディスプレイへフォールバックする)。
